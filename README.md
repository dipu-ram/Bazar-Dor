
# 🛒 Bazar Dor — বাজারদর

A modern, responsive web application to check daily market prices in Bangladesh and compare product prices across markets.

## ✨ Features

- 📊 Daily market price tracking
- 🛍️ Product categories and details
- ⚖️ Market price comparison
- 📈 Price change monitoring
- 🔐 User authentication with Better Auth
- 📱 Responsive design
- ⚡ REST API integration

## 🛠️ Tech Stack

- Next.js
- React & TypeScript
- Tailwind CSS
- MongoDB
- Better Auth
- Lucide React

## 🚀 Getting Started

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd bazar-dor
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## ⚙️ Environment Variables

Create a `.env.local` file and configure:

```env
BAZARDOR_API_URL=YOUR_API_BASE_URL
MONGODB_URI=YOUR_MONGODB_CONNECTION_STRING
BETTER_AUTH_SECRET=YOUR_SECURE_RANDOM_SECRET
BETTER_AUTH_URL=http://localhost:3000
```

**Never upload secrets or `.env.local` to GitHub.**

## 🌐 Deployment

Deploy with [Vercel](https://vercel.com/). Configure your environment variables before deployment.
